= Monitor and investigate alerts in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Jira: SPSPM-3316, SPSPM-3496

Monitor and investigate alerts in NetApp Console (local deployment) to keep your storage healthy and minimize disruption.

View active alerts across your entire organization or a specific fleet, prioritize them by severity and impact area, and investigate root causes so you can resolve issues before they escalate.

.Required access role
All roles except Federation admin and Federation viewer. Federation admins and viewers cannot view alerts. link:reference-iam-predefined-roles.html[Learn about access roles].

For ONTAP alerts, you can access tools such as System Manager and Workload analyzer directly from the Alerts page to investigate and resolve issues. 

For external reporting, you can export the alerts list to a CSV file for offline analysis.

NOTE: You can also set up notification rules to receive alerts by email or webhook. link:task-alert-rules-manage.html[Learn how to set up alert notifications].

== View the alerts dashboard

You can filter the alerts dashboard to view alerts for your entire organization or for a specific fleet. The dashboard provides a summary of active alerts, including their severity and impact area. Additionally, you can filter the dashboard to view only critical alerts or only alerts for a specific impact area.

The dashboard also includes a chart that shows the distribution of alerts over the past 24 hours, which can help you identify trends and patterns in your alert activity.


.Steps

. Select *Health > Alerts > Overview*.
. From the scope selector, choose one of the following:
+
* *All* (default) to see alerts across all fleets you have access to
* A specific fleet to see alerts only for that fleet

. Filter the dashboard according to the alerts you need to view, including:
+
* Severity (Critical, Warning, or Informational)
* Critical alerts grouped by impact area
* Impact area (Security, Protection, Availability, Performance, Capacity, or Configuration)

== View all alerts

Use the Alerts tab to view the full list of active alerts for the scope you've selected. You can also search the list for specific alerts by name or description.

.Steps

. Select *Health > Alerts > Overview*.
. From the scope selector, choose one of the following:
+
* *All* (default) to see alerts across all fleets you have access to
* A specific fleet to see alerts only for that fleet
. Select the *Alerts* tab to view the full list of active alerts for the selected scope.

. Optionally, search the list for a specific alert by name or description.
+
image:screenshot-alerts-search.png["Search alerts by name or description"]

== View alerts by system
You can view alerts associated with a specific system within a fleet or your organization.

.Steps
. Select *Health > Alerts > Overview*.
. From the scope selector, choose one of the following:
+
* *All* (default) to see alerts across all fleets you have access to
* A specific fleet to see alerts only for that fleet
. Select the *Systems health* tab to view a summary of the alerts associated with the systems within the scope you've selected.
. Select *View alerts* on the row of the respective system to view the full list of active alerts associated with that system.


== Investigate an alert
You can investigate an alert to understand what triggered it and who received a notification.

When investigating an ONTAP alert, you can also go directly to the System Manager interface for the system that generated the alert to view additional details and take action.

.Steps
. Select *Health > Alerts > Overview*.
. From the scope selector, choose one of the following:
+
* *All* (default) to see alerts across all fleets you have access to
* A specific fleet to see alerts only for that fleet
. In either tab, select the name of the alert you want to investigate to view its details.
+
image:screenshot-alerts-investigate.png["View alert details"]
. If applicable, select the VM or cluster name to open the System Manager interface for the system that generated the alert.
+
image:screenshot-alerts-details.png["View alert details and navigate to System Manager"]

== Analyze an alert
You can analyze an ONTAP alert in Workload Analyzer to understand what triggered it.

When investigating an ONTAP alert, you can also go directly to the System Manager interface for the system that generated the alert to view additional details and take action.

.Steps
. Select *Health > Alerts > Overview*.
. From the scope selector, choose one of the following:
+
* *All* (default) to see alerts across all fleets you have access to
* A specific fleet to see alerts only for that fleet
. Select the *Systems health* tab to view the full list of active alerts for the selected scope.
. In either tab, select the name of the alert you want to investigate to view its details.
+
image:screenshot-alerts-investigate.png["View alert details"]
. If applicable, select *Analyze* to open the Workload Analyzer interface for the system that generated the alert.
+
image:screenshot-alerts-analyze.png["View alert details and navigate to Workload Analyzer"]

. Enter the time range that covers the period when the alert was triggered, then select *Analyze* to view the analysis results. link:concept-workload-analyzer.html[Learn about Workload Analyzer.]

== Export alerts to CSV

Export the alerts list in the NetApp Console (local deployment) to a CSV file for offline analysis or reporting. The export reflects the current scope (organization or fleet), search text, and filters.


.Steps

. Select *Health > Alerts* and then select the *Alerts* tab.
. Set the scope (organization or fleet) and apply any filters or search text you want included in the export.
. Select the download icon to export the alerts list to a CSV file.
