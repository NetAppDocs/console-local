= View alerts in NetApp Console (local)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Jira: SPSPM-3316, SPSPM-3496

View active alerts in the NetApp Console (local) from the alerts overview page. By default, the page shows an organization-wide view; you can switch to a fleet-wide view to focus on alerts for a specific fleet.

.Required role


== View ONTAP alerts

.Steps

. From the left navigation, select *Health > Alerts*.
. From the scope selector, choose one of the following:
+
* *All* (default) to see alerts across all fleets you have access to
* A specific fleet to see alerts only for that fleet

. Review the alert summary, including:
+
* Alert distribution by severity
* Alert distribution by impact area
* Critical alerts grouped by impact area
* Alert count distribution over the past 24 hours

. Select the *Alerts* tab to see the full list of active alerts.



== Export alerts to CSV

Export the alerts list in the NetApp Console (local) to a CSV file for offline analysis or reporting. The export reflects the current scope (organization or fleet), search text, and filters.


.Steps

. From the left navigation, select *Health > Alerts* and then select the *Alerts* tab.
. Set the scope (organization or fleet) and apply any filters or search text you want included in the export.
. Select *Download CSV*.
. Open the file from your browser's downloads location.
