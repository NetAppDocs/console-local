= Manage custom dashboards in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Source: NetApp Console Local — Customizable Dashboard (Confluence page 560148946)

Manage custom dashboards in NetApp Console (local deployment) to keep views aligned with operations. You can edit, clone, and delete dashboards as teams, fleets, and priorities change.

== Before you begin

Open *Storage > Dashboards* and identify the dashboard you want to modify.


== Edit a dashboard

.Steps

. Select *Storage > Dashboards*.

. Open the dashboard you want to edit.

. Modify the dashboard as needed:
+
* Update the name or description.
* Add, remove, or reorder cards.
* Drag cards to new positions or resize them on the grid.

. Select *Save*.

== Clone a dashboard

.Steps

. Select *Storage > Dashboards*.

. For the dashboard you want to duplicate, select *Clone*.
+
Console (local deployment) creates a copy that includes all cards from the original dashboard.

. Edit the cloned dashboard as needed, then save it.

== Delete a dashboard

.Steps

. Select *Storage > Dashboards*.

. For the dashboard you want to remove, select *Delete*.

. Confirm the deletion.
