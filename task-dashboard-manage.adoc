= Keep dashboards current in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Source: NetApp Console Local — Customizable Dashboard (Confluence page 560148946)

Manage custom dashboards in NetApp Console (local deployment) to keep views aligned with operations. You can edit, duplicate, and delete dashboards as teams, fleets, and priorities change.

This task applies only to custom dashboards under *Storage > Dashboards*. Built-in Home page dashboards are predefined and cannot be edited in the same way.

From *Storage > Dashboards*, select a dashboard in the table to open it. The table includes predefined dashboards and custom dashboards you create. For details, see link:task-dashboard-view-additional.html[View additional dashboards in NetApp Console (local deployment)].

== What you can adjust while viewing a dashboard

While viewing a custom dashboard, you can:

* Add, edit, or delete cards
* Reorder and resize cards
* Change time window and aggregation settings

Time window and aggregation are configured at the dashboard level. The values you select apply to all cards in that dashboard.



== Update a dashboard as priorities change

Edit a dashboard when your operational priorities change and you need to adjust which cards and metrics are visible.

.Steps

. Select *Storage > Dashboards*.

. Open the dashboard you want to edit.

. Modify an existing card on the dashboard by selecting Edit from the actions menu.

. Add a new card to the dashboard by selecting *Add Card* and following the steps in link:task-customize-dashboard-cards.html[Customize cards in NetApp Console (local deployment)].



. Select *Save changes*.

== Reuse a custom dashboard for another resource or fleet

Duplicate a dashboard when you want to reuse a proven layout for another team, fleet, or monitoring scenario without rebuilding it from scratch. 

.Steps

. Select *Storage > Dashboards*.

. For the dashboard you want to duplicate, select *Duplicate* from the actions menu.
+
Console (local deployment) creates a copy that includes all cards from the original dashboard.

. Provide a name and description for the duplicated dashboard.


. Select the duplicate dashboard you just created and select *Edit* from the actions menu to make further changes, then select *Save changes*.

== Remove dashboards you no longer use

Delete a dashboard when it no longer supports current operations and you want to keep your dashboard list focused on active use cases.

.Steps

. Select *Storage > Dashboards*.

. For the dashboard you want to remove, select *Delete*.

. Confirm the deletion.
