= Quick start for setting up NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
After you install NetApp Console (local deployment), set up your organization so that the right teams can securely manage the right storage resources. Follow these steps to plan your structure, organize resources, add members, configure integrations, and enable data services.

.Required access roles
Super admin or Organization admin. link:reference-iam-predefined-roles.html[Learn about access roles].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] Install NetApp Console (local deployment)

[role="quick-margin-list"]
* Review the installation workflow to understand the deployment process. link:concept-deploy-netapp-console-local.html[Review the installation workflow].

* Install NetApp Console (local deployment) in your vCenter. link:task-install-agent-on-prem-ova.html[Install NetApp Console (local deployment)].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] Plan your organization

[role="quick-margin-list"]
* Learn how folders and fleets organize your resources. link:concept-folders-fleets-overview.html[Learn about folders and fleets].

* Understand how role-based access control (RBAC) grants members the access they need. link:concept-iam-rbac.html[Understand RBAC].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] Set up your organization

[role="quick-margin-list"]
* Create the folder and fleet hierarchy that matches your business structure. link:task-iam-manage-folders-fleets.html[Create folders and fleets].

* Add your storage systems to NetApp Console (local deployment). link:task-discover-storage.html[Add storage systems].

* Associate resources with the correct folders and fleets. link:task-iam-manage-resources.html[Associate resources to folders and fleets].

* Add members and assign their initial roles. link:task-iam-manage-members-permissions.html[Add members and assign roles].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four] Configure integrations and services

[role="quick-margin-list"]
* Integrate with Active Directory so that directory users can access the Console (local deployment). link:task-iam-active-directory-integrate.html[Integrate with Active Directory].

* Connect your large language model (LLM) to enable the Console assistant and AI-assisted management. link:task-llm-connect.html[Connect your LLM].

* Configure how the Console (local deployment) delivers notifications. link:task-console-configure-notifications-delivery.html[Configure notification delivery].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png[Five] Set up data services

[role="quick-margin-list"]
* Subscribe to the data services you want to use. link:task-data-services-subscribe.html[Subscribe to data services].

* Grant members access to the data services. link:task-data-services-access-grant.html[Grant access to data services].
