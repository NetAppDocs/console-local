= Associating storage classes with fleets in NetApp Console (local)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Jira: SPSPM-3309

Associate a storage class with a fleet to make an approved set of storage standards available for provisioning in that fleet. This helps teams provision consistently and supports ongoing governance by evaluating workloads against the class standards.

Associate storage classes with fleets when you want to:

- Scope approved standards by environment (for example, production vs. development).
- Ensure provisioning workflows in a fleet use a consistent baseline for performance, capacity behavior, security, and data protection.
- Limit which standards are available to operators in a given fleet.

== Required role

You must have permissions to manage storage standards for the target fleet.

== Associate a storage class with a fleet

.Steps

(Steps to be confirmed with the product team, as the UI may change. The following steps are a placeholder.)

. Identify the target fleet where the class should be available.
. Select the storage class or fleet configuration area.
. Associate the storage class with the fleet.
. Save and confirm the association.
