= Associate storage classes with fleets in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Jira: SPSPM-3309

Associate a storage class with a fleet to make an approved set of storage standards available when provisioning storage in that fleet. This helps teams provision consistently and supports ongoing compliance monitoring by checking workloads against the storage class.

.Required access roles
Super admin, Organization admin, Folder or fleet admin, or Storage admin. link:reference-iam-predefined-roles.html[Learn about access roles].

== When to associate a storage class with a fleet

Associate storage classes with fleets to:

- Scope approved standards by environment (for example, production vs. development).
- Ensure provisioning uses a consistent baseline for performance, capacity behavior, security, and data protection.
- Limit which standards are available to operators in a given fleet.

== Associate a storage class with a fleet

Associate a storage class with a fleet so it's available for provisioning and ongoing compliance monitoring within that fleet.

.Steps

. Open the fleet you want to manage.
. Locate the fleet configuration area for storage classes.
. Select one or more storage classes to associate with the fleet.
. Select *Save*.

.Verify

. Start a provisioning workflow in the fleet and confirm the storage class is available for selection.
