= Integrate NetApp Console Local with your SIEM tools
:icons: font
:imagesdir: ./media/

[.lead]
Integrate NetApp Console Local with your security information and event management (SIEM) tools to centralize logging, monitoring, and security event correlation.

NetApp Console Local generates an audit record for each administrative action, such as provisioning requests, configuration changes, access grants, policy updates, and login events. By default, these records exist only within the Console Local. Integrating with a SIEM forwards these events to your centralized security monitoring system. Your security operations team can then correlate Console Local activity with other system events, trigger alerts on suspicious patterns, and retain logs according to your organization's security policies.

For organizations that must follow compliance rules like SOC 2, ISO 27001, or internal security standards, SIEM integration gives auditors the proof they need. It also brings storage management activity into visibility for the teams responsible for security monitoring.

== Prerequisites

Before you configure SIEM integration, ensure the following are in place:

* Have the Organization admin role in the NetApp Console Local
* Have a running SIEM platform that accepts syslog-formatted events (such as Splunk, IBM QRadar, or Microsoft Sentinel)
* Know the IP address or hostname and the port your SIEM uses to receive syslog input
* Confirm that the Console Local can reach your SIEM receiver over the network
* Confirm whether your SIEM requires UDP or TCP transport for syslog, and whether it uses TLS encryption
