Use custom dashboards to build personalized monitoring views of your fleet. You assemble each dashboard from card templates, choosing the scope, metrics, aggregation, and target resources that matter to you.

== What a custom dashboard is

A custom dashboard is a saved collection of cards that you arrange on a grid. Each card is created from a predefined template that defines a metric and a visualization, such as a line chart, bar chart, pie or doughnut chart, table, or single-number stat panel. After you add a card, you customize its scope, aggregation, target resources, and time window.

Each dashboard and card is private to you. Every card shows data only for the storage resources you are authorized to view.

== What you can monitor

Card templates are organized by metric type so you can focus a dashboard on a specific operational area:

Performance::
Latency, IOPS, throughput, utilization, and performance capacity across the fleet, systems, SVMs, volumes, and LUNs.

Capacity::
Used capacity, free capacity, capacity used percentage, and snapshot capacity across the fleet, systems, SVMs, volumes, LUNs, and local tiers.

Health::
Health status, degraded or critical object counts, failed disks, network interface errors, and hot objects.

Alerts::
Critical alert counts, alerts by severity, alerts by impact area, recent alerts, and alert trends over time.

== Target objects

You can scope cards to any level of the ONTAP storage hierarchy: fleet, cluster, system (node), SVM, volume, LUN, and local tier (aggregate). The available target objects depend on the card template you select.

== High-level workflow

Building and maintaining a custom dashboard involves the following steps.

. *Create a dashboard.*
Add a new dashboard, then give it a name and description.
+
link:task-dashboard-create.html[Create a custom dashboard]

. *Add cards.*
Add cards from templates, choosing the scope, metric type, aggregation, target resources, and time window. Preview each card with live data before you add it.
+
link:task-dashboard-cards-add.html[Add cards to a dashboard]

. *Arrange and save.*
Position and resize cards on the grid, then save the dashboard. Saved dashboards are available under *Storage > Dashboards*.

. *Maintain dashboards.*
Edit, clone, or delete dashboards as your monitoring needs change.
+
link:task-dashboard-manage.html[Manage custom dashboards]

For the full list of available card templates, see link:reference-dashboard-card-templates.html[Custom dashboard card templates].
