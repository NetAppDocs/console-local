NetApp Console (local deployment) provides out-of-the-box dashboards that are ready to use, and the ability to build your own custom dashboards for role-specific monitoring. Use built-in views for quick, organization-level visibility, and use custom dashboards when you need targeted metrics for specific teams, fleets, or operational workflows.

== Choose a dashboard type

Out-of-the-box dashboards::
Out-of-the-box dashboards provide ready-to-use monitoring panes for areas such as capacity, alerts, performance capacity, licenses, and data protection status. These views are preconfigured and update automatically.

Custom dashboards::
Custom dashboards provide role-specific monitoring views built from predefined cards, including selectable scope, metrics, target resources, and time windows.

Predefined dashboards and custom dashboards are both available in the dashboards experience.

For details about built-in Home page dashboards, see link:task-storage-dashboard.html[View Home page metrics in NetApp Console (local deployment)].

== Understand custom dashboards

A custom dashboard is a saved collection of cards that you arrange on a grid. Each card is based on a predefined card template with a metric and a chart type. When you add the card, you configure the data scope, target objects, aggregation, and time window.

Custom dashboards and cards are private to you. Every card shows data only for the storage resources you are authorized to view.

== What you can monitor

Card templates are organized by metric type so you can focus a dashboard on a specific operational area:

Performance::
Latency, IOPS, throughput, utilization, and performance capacity across the fleet, systems, SVMs, volumes, and LUNs.

Capacity::
Used capacity, free capacity, capacity used percentage, and snapshot capacity across the fleet, systems, SVMs, volumes, LUNs, and local tiers.

Health::
Health status, degraded or critical object counts, failed disks, network interface errors, and hot objects.

Alerts::
Critical alert counts, alerts by severity, alerts by impact area, recent alerts, and alert trends over time.

For a complete catalog of predefined cards and metrics, see link:reference-dashboard-card-templates.html[Custom dashboard cards and metrics reference].

== ONTAP object hierarchy

You can scope cards to any level of the ONTAP storage hierarchy: fleet, cluster, system (node), SVM, volume, LUN, and local tier (aggregate). The available target objects depend on the card template you select.

== Operational focus areas

Dashboard views can be organized around common storage administration goals such as workload performance triage, capacity planning, health risk detection, and alert prioritization.
