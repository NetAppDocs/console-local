= Associate a Console agent with other folders and fleets
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Associate Console agents with specific fleets to enable resource management and data service access. Resources discovered through a Console agent require both the resource and agent to be associated with the same respective fleets for team access.

Super admins and Org admins can create agents and associate any agent with any fleet or folder. Folder or fleet admins can only associate existing agents with folders and fleets that they have permissions for.
link:reference-iam-predefined-roles.html[Learn more about the actions that a _Folder or fleet admin_ can complete].

NOTE: Users with the Org admin role can add resources to folder to delegate the task of associating the resource with fleets to Folder or fleet admins of the respective folder. link:task-iam-manage-folders-fleets.html#associate-resource-folder[Learn about associating a resource with a folder].


.Steps

. Select *Administration > Identity and access* > *Agents*.


. From the table, find the Console agent that you want to associate.
+
Use the search above the table to find a specific Console agent or filter the table by resource hierarchy.

. To view the folders and fleets linked to the Console agent, select image:icon-action.png["Three dot icon"] and then select *View details*.
+
The page displays details about the folders and fleets that are associated with the Console agent.

. Select *Associate to folder or fleet*.

. Select a folder or fleet and then select *Accept*.

. To associate the Console agent with an additional folder or fleet, select *Add a folder or fleet* and then select the folder or fleet.

. Select *Associate Agent*.


.After you finish

Associate the Console agent's resources with the same folders and fleets from the *Resources* page.

link:task-iam-manage-resources.html#associate-resource[Learn how to associate a resource with folders and fleets].
