= Add cards to a dashboard (advanced) in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Source: NetApp Console Local — Customizable Dashboard (Confluence page 560148946)

Use this advanced topic when you need detailed card customization after completing link:task-dashboard-create.html[Create a custom dashboard].

Add cards to a custom dashboard in NetApp Console (local deployment) by configuring scope, aggregation, target resources, and time window for each card.

== Before you begin

* Create or open a dashboard where you want to place cards.
* Review available templates and metrics in link:reference-dashboard-card-templates.html[Custom dashboard card templates and metrics reference].


== Add a card from the Add Card menu

.Steps

. Open the dashboard you want to add a card to.

. Select *Add Card*.

. Select the *Scope* for the card, such as fleet, system, or volume.

. Select the *Metric Type*: *Performance*, *Capacity*, *Health*, or *Alerts*.

. Select a *Card Template*.
+
The template defines the metric and chart type.

. Select the *Aggregation*, such as fleet-wide or top N elements.

. Select the *Target Resource Type* and then the specific *Target Resources* to monitor.

. Select the *Time Window*: 30 minutes, 1 hour, 24 hours (default), 48 hours, 7 days, or 30 days.

. Review the card preview, which shows live data.

. Enter a name and description for the card.

. Select *Add* to add the card to the dashboard.

. Repeat these steps for each additional card, then save the dashboard.

== Create a card from the Card Templates menu

.Steps

. Select *Storage > Dashboards > Card Templates*.

. Browse, sort, or filter the templates by metric type, metric, or target resource type.

. Select a template, then select *Create Card from Template*.

. Customize the scope, aggregation, target resource type, target resources, and time window.

. Review the card preview and enter a name and description.

. Add the card to an existing dashboard or create a new dashboard.

. Save the dashboard.
