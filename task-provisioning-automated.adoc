= Provision storage automatically in NetApp Console (local)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Use automated provisioning to allocate storage based on your storage class policies. NetApp Console (local) recommends (and can apply) optimal settings and placement, reducing manual steps while keeping provisioning consistent with your standards.

Use automated provisioning when you want Console (local) to use the selected storage class to recommend best-fit placement and apply settings consistently—for example, when:

- you want operators to provision safely without deep ONTAP decision-making
- you want consistent outcomes across fleets
- you want to reduce configuration drift introduced during provisioning
