= Get started with identity and access in NetApp Console (local)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
When you install NetApp Console (local), you're prompted to create a new organization. The organization includes one member (an Organization admin) and one default fleet. Use this setup order to create your folder and fleet hierarchy, add members, add or discover resources, and place those resources in the correct fleets.

You need the *Org admin* or *Super admin* role to complete initial setup. After setup is complete, use the related task topics to manage resources, member access, and fleet access as your organization changes.

Follow this setup order to align with most organizations.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] Add or discover resources

[role="quick-margin-para"]
Add or discover systems in Console (local). During initial setup, systems are typically added while the default fleet is selected.

[role="quick-margin-para"]
Learn how to create or discover resources:

[role="quick-margin-list"]

* https://docs.netapp.com/us-en/storage-management-ontap-onprem/index.html[On-premises ONTAP clusters^]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] Create your folder and fleet hierarchy

[role="quick-margin-para"]
Use the default fleet or create additional fleets and folders that match your business hierarchy.

[role="quick-margin-para"]
link:task-iam-manage-folders-fleets.html[Learn how to organize your resources with folders and fleets].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] Place resources in the correct fleets

[role="quick-margin-para"]
Adding or discovering a system in Console (local) automatically associates the resource with the currently selected fleet. To make a system available to the right teams, associate it with the appropriate fleets in your hierarchy.

[role="quick-margin-list"]
* link:task-iam-manage-resources.html[Learn how to manage resources in folders and fleets].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four] Add members and assign starting permissions

[role="quick-margin-para"]
Add members and assign them roles at the organization, folder, or fleet level based on what they manage.

[role="quick-margin-para"]
link:task-iam-manage-members-permissions.html[Learn how to manage members and their permissions].
