= Integrate NetApp Console Local with Active Directory
:icons: font
:imagesdir: ./media/

[.lead]
Integrate NetApp Console Local with Active Directory for centralized user management. Use your directory services for authentication and authorization.

.Required role
Super admin or organization admin.

When you integrate with Active Directory, Console Local authenticates users through your existing directory and grants or revokes access based on group membership. This aligns access with your identity lifecycle and eliminates separate user management.

Active Directory integration also helps you meet compliance requirements by applying your existing controls, audit trails, and policies to Console Local access.

== Before you begin

Before you integrate with Active Directory, make sure you have:

* An Active Directory domain and credentials that can query the directory
* The LDAP server address and the base distinguished name (DN) for the directory tree
* Network access from Console Local to your LDAP server on port 389 (LDAP) or 636 (LDAPS)
* SSL/TLS certificates, if you plan to use LDAPS

.Steps
. Select *Administration > Identity and access*.
. Select *Directory services* to open the Federations page.
. Select *Add integration*.
. Enter the connection details for your Active Directory server:
+
* A descriptive name for the integration.
* The *LDAP host*: hostname or IP address of your LDAP server. For multiple servers, enter the primary.
* The port: 389 for LDAP or 636 for LDAPS.
* The *Connection timeout* in milliseconds. The default is 1000 ms.
. Select *Use SSL/TLS* to use LDAPS. Confirm that your LDAP server supports LDAPS and that Console Local can access the required certificates.
. Test the connection. If it fails, check the LDAP host, port, network connectivity, and SSL/TLS certificates.
. After the test succeeds, enter the directory and user details:
+
* *Base DN*: the starting point for LDAP queries. For example, for the domain `example.com`, use `DC=example,DC=com`.
* *User DN*: a user account with permission to query the directory. For example, `CN=ldap-reader,OU=Service Accounts,DC=example,DC=com`.
. Select *Add* to save the integration.
