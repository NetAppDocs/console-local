== Supported ONTAP platforms

Alerting is supported on ONTAP 9.12.1 and later for the following platforms:

[cols="2,1", options="header"]
|===
| Platform | Alerting supported
| AFF | Yes
| FAS | Yes
| ASA r1 | Yes
| ASA R2 | Yes
| AFX (OAM) | Yes
| Cloud Volumes ONTAP | Yes
| FSx for ONTAP, Google Cloud NetApp Volumes, Azure NetApp Files | No
|===
