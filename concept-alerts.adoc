= Learn about alerts in NetApp Console Local
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Alerts in NetApp Console Local help you identify and respond to issues across the on-premises ONTAP clusters in your organization. The alerting feature is part of the fleet monitoring experience and lets you view alerts on objects that belong to a fleet for which you have permission, or get an org-wide view across all fleets.

NOTE: Stub page. Content to be developed based on the alerting functional specification.

== What you can do with alerts

* View alerts at the organization level or for a specific fleet
* Investigate the details of an active alert, including impact area and severity
* Monitor systems health by cluster
* Search, filter, and export alerts
* Enable or disable alert rules
* Receive notifications when alerts are raised

== Alert sources

Alerts are raised by on-premises ONTAP clusters through the Harvest integration with NetApp Console Local.
