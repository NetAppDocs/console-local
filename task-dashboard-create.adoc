Create a custom dashboard in the NetApp Console (local) to assemble the cards you need into a single monitoring view. After you create a dashboard, you add cards from templates and save the result for ongoing use.

.Required role


== Create a dashboard

.Steps

. Select *Storage > Dashboards*.

. Select *Add Dashboard*.
+
The Console (local) creates a dashboard with a default name and no description.

. Add one or more cards to the dashboard.
+
link:task-dashboard-cards-add.html[Add cards to a dashboard]

. Arrange the cards on the grid by dragging them to new positions and resizing them as needed.

. Edit the dashboard name and description to describe its purpose.

. Select *Save*.
+
The saved dashboard is available under *Storage > Dashboards*.
