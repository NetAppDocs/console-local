// Source: NetApp Console Local — Customizable Dashboard (Confluence page 560148946)

Create a custom dashboard in NetApp Console (local deployment), add cards, and save a monitoring view for daily operations.

If you only need organization-level monitoring that is ready to use, start with the built-in Home page dashboards. Create a custom dashboard when you need a role-specific view, resource-level targeting, or a tailored card layout.

== Before you begin

* Confirm that storage systems are added to a Console fleet.
* Identify the metric types and resources you want the dashboard to track.


== Build a dashboard for your monitoring goals

Create a dashboard when you need one place to monitor the metrics that matter to your role, such as fleet health, performance hotspots, and alert trends.

.Steps

. Select *Storage > Dashboards*.

. Select *Add Dashboard*.
+
Console (local deployment) creates a new dashboard with a default name and no description.

include::_include/dashboard-cards-steps.adoc[tag=core-add-card-flow]


. Select the pencil icon to edit the dashboard name and description to describe its purpose.

. Select *Save changes*.
+
The saved dashboard is available under *Storage > Dashboards*.

For advanced card customization, see link:task-customize-dashboard-cards.html[Customize dashboard cards in NetApp Console (local deployment)].
