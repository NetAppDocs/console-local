= Edit or delete folders and storage fleets in NetApp Console Local
:icons: font
:imagesdir: ./media/

[.lead]
Edit a folder or storage fleet to update its name, or delete a folder or fleet that you no longer need.

== Rename a folder or fleet

You can rename a folder or fleet at any time. Renaming does not affect associated resources or member access.

.Steps

. From the Organization page, navigate to a folder or fleet in the table, select image:icon-action.png[An icon with three dots] and then select *Edit folder* or *Edit fleet*.

. Enter a new name.

. Select *Apply*.

== Delete a folder

Delete a folder when you no longer need it, such as after restructuring your organization.

Before you delete a folder, make sure it does not contain any fleets or resources. Move any fleets or resources to another location first.

.Steps

. From the Organization page, navigate to the folder in the table, select image:icon-action.png[An icon with three dots] and then select *Delete*.

. Confirm that you want to delete the folder.

== Delete a storage fleet

Delete a fleet when you no longer need it, such as after consolidating storage systems into other fleets or after a team restructuring.

Before you delete a fleet, be aware of the following constraints:

* You must remove all storage systems from the fleet before you can delete it. A non-empty fleet cannot be deleted.
* You cannot delete the last fleet in the organization. At least one fleet must exist at all times.

.Steps

. From the Organization page, navigate to the fleet in the table.

. Remove all storage systems from the fleet.
+
link:task-storage-fleets-organize.html[Learn how to organize storage into fleets].

. Select image:icon-action.png[An icon with three dots] and then select *Delete*.

. Confirm that you want to delete the fleet.
