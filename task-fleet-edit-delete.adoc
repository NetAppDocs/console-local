= Edit or delete a storage fleet
:icons: font
:imagesdir: ./media/

[.lead]
Edit a storage fleet to update its name or description, or delete a fleet that you no longer need.

== Edit a storage fleet

You can update the name and description of a fleet at any time. Editing a fleet does not affect the storage systems or user assignments associated with it.

.Steps

. From the NetApp Console Local, select *Storage Fleets*.

. Navigate to the fleet in the table, select image:icon-action.png[An icon with three dots] and then select *Edit Fleet*.

. Update the fleet name or description.

. Select *Apply*.

== Delete a storage fleet

Delete a fleet when you no longer need it, such as after consolidating storage systems into other fleets or after a team restructuring.

Before you delete a fleet, be aware of the following constraints:

* You must remove all storage systems from the fleet before you can delete it. A non-empty fleet cannot be deleted.
* You cannot delete the last fleet in the organization. At least one fleet must exist at all times.

.Steps

. From the NetApp Console Local, select *Storage Fleets*.

. Remove all storage systems from the fleet.
+
link:task-storage-fleets-organize.html[Learn how to organize storage into fleets].

. Navigate to the fleet in the table, select image:icon-action.png[An icon with three dots] and then select *Delete*.

. Confirm that you want to delete the fleet.
