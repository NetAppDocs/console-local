= Get started with dashboards in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Start with built-in dashboards for quick visibility, then create and refine custom dashboards when you need targeted monitoring views for teams, fleets, or operational workflows.

.Required access roles
A role that allows access to *Storage > Dashboards* and the resources you want to monitor.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] Review built-in dashboards

[role="quick-margin-para"]
Use out-of-the-box Home page dashboards to check organization-level capacity, alerts, performance, and data protection status.

[role="quick-margin-list"]
* link:task-storage-dashboard.html[View Home page metrics in NetApp Console (local deployment)]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] View additional dashboards

[role="quick-margin-para"]
Open *Storage > Dashboards* to view the dashboard table, which includes predefined dashboards and custom dashboards you create. Select any listed dashboard to view it.

[role="quick-margin-para"]
If Home page dashboards do not show the view you need, use predefined dashboards in *Storage > Dashboards* for additional role-specific views.

[role="quick-margin-para"]
Create a custom dashboard when you need a role-specific view for selected resources, metrics, and time windows.

[role="quick-margin-list"]
* link:task-dashboard-view-additional.html[View additional dashboards in NetApp Console (local deployment)]
* link:task-dashboard-create.html[Create a custom dashboard]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] Keep dashboards current

[role="quick-margin-para"]
Update dashboards as priorities change by editing, duplicating, or deleting custom dashboards.

[role="quick-margin-list"]
* link:task-dashboard-manage.html[Manage custom dashboards]
