= Configure notifications and alert policies in NetApp Console Local
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Set up notification rules in the NetApp Console Local to get alerts when storage events exceed limits or require attention.


.Steps

. Select *Health > Alerts > Notification rules*.
. Select *Add rule*.
. Define the notification rule, including:
+
* Rule name and description
* The service where the alert originates, such as ONTAP management
* The access role of the users who will receive the notification
* The severity level that triggers the notification
* The impact area(s) affected
. Select delivery channels for the notification.
+ 
* Your organization admin must set up your email server to enable automatic email notifications. When configured, email notifications happen automatically when rules are configured.
* The NetApp Console UI displays all notifications by default.
* You can send notifications to external systems with a webhook only if your organization admin has already configured a webhook.

. Select *Create*.
