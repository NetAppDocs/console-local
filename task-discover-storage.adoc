= Add storage in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Jira: SPSPM-3497

Discover on-premises ONTAP clusters in the NetApp Console (local deployment) so you can manage and monitor them from a single interface.

.Required access roles
Super admin, Organization admin, Folder or fleet admin, or Storage admin. link:reference-iam-predefined-roles.html[Learn about access roles].

NOTE: Stub page. Content to be developed.

You have the cluster management IP address and credentials for each ONTAP cluster you want to add.


.Steps

. From the left navigation, select *Storage*.
. Select *Discover storage*.
. Enter the cluster details and credentials.
. Select *Discover*.
