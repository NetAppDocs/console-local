== Before you begin

* You have the cluster management IP address and credentials for each ONTAP cluster you want to discover.
* The Console agent has network access to the clusters.

== Steps

. From the left navigation, select *Storage*.
. Select *Discover storage*.
. Enter the cluster details and credentials.
. Select *Discover*.
