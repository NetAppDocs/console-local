= Create folders and storage fleets
:icons: font
:imagesdir: ./media/

[.lead]
Create folders and storage fleets in the NetApp Console Local to organize your resources and manage access. Folders group related fleets, and fleets group storage systems.

== About this task

An organization consists of folders and fleets that form a resource hierarchy:

* *Folders* help you organize related fleets. For example, you might create a top-level folder for each region and then create fleets within each folder. Folders can contain other folders or fleets, but they cannot have storage systems directly associated with them.
* *Fleets* group storage systems that you manage together. You might organize fleets by environment (production, development, test), by business unit, by data center location, or by application tier.

The NetApp Console Local creates one fleet for you when you set up your organization. You can create additional folders and fleets to match your organizational structure.

You can create up to seven levels of folders and fleets in your organization's resource hierarchy.

== Create a folder

Create a folder to group related fleets.

.Steps

. From the NetApp Console Local, select *Administration* > *Identity and access*.

. Select *Organization*.

. Select *Add folder or fleet*.

. Select *Folder*.

. Enter a name and choose a location for the folder.
+
You can place the folder directly under the organization or inside another folder.

. Select *Add*.

== Create a storage fleet

Create a fleet to group storage systems for unified management.

.Steps

. From the NetApp Console Local, select *Administration* > *Identity and access*.

. Select *Organization*.

. Select *Add folder or fleet*.

. Select *Fleet*.

. Enter a name and description for the fleet.
+
Choose a name that reflects how this fleet fits into your operational model. For example, "Production - US East" or "Engineering - Dev/Test."

. Choose a location for the fleet.
+
You can place the fleet directly under the organization or inside a folder.

. Select *Add*.

NOTE: Members can't access resources in a folder until those resources are assigned to a fleet. Use folders to hold resources temporarily until you create the necessary fleets. This can help the Organization admin delegate resource allocation to a Folder or fleet admin, who then assigns resources to fleets within the folder.

== After you finish

After you create folders and fleets, you can:

* Organize discovered storage systems into fleets. link:task-storage-fleets-organize.html[Learn how to organize storage into fleets].
* Assign users to folders or fleets to grant them management access. link:task-users-fleets-assign.html[Learn how to assign users to fleets].
