= Enable or disable an alert rule
:icons: font
:imagesdir: ./media/

[.lead]
Enable or disable individual alert rules in the NetApp Console Local to control which conditions raise alerts. Disable alert rules that are not relevant to your environment to reduce noise; enable rules to start receiving alerts again.

NOTE: Stub page. Content to be developed.

.Steps

. From the left navigation, select *Alerts*.
. Open the alert rules management page.
. Locate the alert rule you want to change.
. Toggle the rule *On* or *Off*.
