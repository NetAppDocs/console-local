= Learn about storage alerts in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
// Jira: SPSPM-3316, SPSPM-3496
Alerts in NetApp Console (local deployment) help you find and resolve issues in your on-premises ONTAP clusters. You can view alerts for fleets you have permission to access. Alerts include information about the impact area and severity of the issue. You can also receive notifications when alerts occur, so you can take action to resolve them quickly.

== What you can do with alerts

* View alerts at the organization level or for a specific fleet
* Investigate the details of an active alert, including impact area and severity
* Search, filter, and export alerts
* Enable or disable alert rules
* Receive notifications when alerts occur

== Alert sources

On-premises ONTAP clusters raise alerts through the Harvest integration with NetApp Console (local deployment).
