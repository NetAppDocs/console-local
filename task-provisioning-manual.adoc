= Provision storage manually in NetApp Console (local)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Manually provision storage in NetApp Console (local) when you need full control over configuration. Create volumes (or LUNs), select the target system, and allocate capacity to meet workload requirements.

Use manual provisioning when you need to control configuration details directly—for example, when:

- creating exception workloads
- migrating a workload with known requirements
- troubleshooting or validating behavior during rollout

In manual provisioning, you can still select a storage class to apply approved standards while retaining explicit control over placement and other selections.

.Steps (for Volume)

. Select *Storage > Management*.

. Select *Fleets*.

. Select the fleet you want to provision into.

. Select *Add*.

. From the menu, select *Volume*.

. Under *Volume details*:
.. Enter a volume name.
.. Enter capacity (and choose units if needed).
.. (Optional) Select a storage class.

. Under *System details*:
.. Choose a system (if prompted).
.. Select a storage VM.

. Under *Host (NAS) details*, choose how hosts access the volume:
.. Export by NFS
.. Share by SMB/CIFS

. Select *Add*.
