= Connect your LLM and enable the NetApp Console assistant
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Connect your large language model (LLM) to the NetApp Console (local deployment) to enable the NetApp Console assistant and AI-assisted storage management. After you connect your LLM, the Console assistant becomes available to users in your organization, who can use natural language to provision storage, investigate alerts, and get answers to storage management questions.

.Required access roles
Super admin or organization admin. link:reference-iam-predefined-roles.html[Learn about access roles].

After you connect your LLM, users open the Console assistant from the dashboard and choose an access mode that controls whether the assistant can change storage infrastructure:

* In *Read only* mode, the assistant answers questions and provides guidance without making changes.
* In *Read/write* mode, the assistant can act on storage infrastructure. Before it makes a change, it shows the details for the user to review and confirm. For asynchronous operations, such as volume creation, the assistant creates a job that the user can check on by asking the assistant.

To connect your LLM, you obtain an API key from your LLM provider and then enter the key and select a model in the Console (local deployment) AI Tools settings. The Console assistant's actions remain guided by the storage policies and role-based access controls that your organization has defined.

== Before you begin

Before you connect your LLM, make sure you have:

* A valid API key from a supported LLM provider. Create the key with your provider and keep it available to paste into the Console (local deployment). Because most providers display the key only once, copy it as soon as you generate it.
* Your user name or single sign-on (SSO) ID for the LLM provider account.
* Network access from the Console (local deployment) to your LLM provider's endpoint.



== Connect your LLM

Enter your API key and select a model in the AI Tools settings to connect your LLM to the Console (local deployment).

.Steps
. Log in to the NetApp Console (local deployment).
. Select *Administration > AI Tools*.
. Select the menu, and then select *Edit*.
. In the *User name* field, enter your user name or SSO ID.
. In the *API key* field, paste the API key from your LLM provider.
. Select a model from the list. For example, `gpt-5-mini`.
. Review the configuration, and then select *Save*.
+
If you encounter LLM errors when you use AI-assisted features, return to the AI Tools settings and verify that the user name, API key, and model are correct.

After you connect your LLM, confirm that the *Console assistant* button appears on the NetApp Console (local deployment) dashboard, and verify that users have the role-based access controls they need for the actions you want them to perform with the assistant.
