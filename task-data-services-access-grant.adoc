= Grant access to data services
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Grant users in your NetApp Console Local organization access to data services so they can use protection, mobility, and analysis features.

NOTE: Stub page. Content to be developed.

== Before you begin

You have the Organization admin role in NetApp Console Local.

== Steps

. Select *Administration > Identity and access*.
. Select the user or group you want to grant access to.
. Assign the appropriate data services role.
. Select *Save*.
