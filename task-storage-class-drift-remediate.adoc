= Remediate storage class drift
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Find drift-related alerts, analyze the drift findings, and remediate workloads that no longer match their storage class intent.

.Required roles
Storage admin (or equivalent) for the fleet that contains the workload.

NOTE: You can only view and remediate workloads in fleets where you have permission.

== Remediate drift

When a workload no longer matches its storage class intent, Console local deployment raises an alert. Use the alert to analyze the drift and apply the recommended remediation.

Some remediations can be applied directly from the alert. Other issues might require updating the workload configuration or assigning a different storage class to restore compliance. The remediation workflow indicates the expected impact before changes are applied.

.Steps

. Select *Storage > Storage classes*.
+
A summary of storage class drift appears in the *Drifts by storage class* area. The complete list appears in the table.

. In the *Drifts* column, select *View* for the relevant storage class.
+
The *Alerts > Overview* page opens with filters applied.

. Select an alert to open the alert details page.

. Select *Analyze*.

. Review the findings in *Workload analyzer*.
+
For configuration drift findings, compare the intended and actual settings to determine what changed.

. Select the recommended remediation action, such as *Fix it*.

. Review the proposed changes and apply the remediation.

. Return to *Storage > Storage classes* and verify that the workload is no longer listed as drifted.
+
Compliance evaluations can take several minutes to reflect recent configuration changes. If the workload is still listed as drifted, return to the alert details page and select *Analyze* to review any remaining findings.
