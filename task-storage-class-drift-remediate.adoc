Use the Alerts workflow to review drift details for a workload and restore compliance with its assigned storage class.

Console opens the *Alerts* page with filters applied.

. Select an alert name to open the alert details page.

== Analyze the drift

. On the alert details page, select *Analyze*.
. Review the drift findings.
. For configuration drift findings, compare *intended* vs *actual* settings to understand what changed.

== Remediate

. On the alert details page, select the recommended action (for example, *Fix it* if available).
. Review the proposed change and proceed only after you understand the expected impact.

[NOTE]
====
Some remediations can be applied in place. Others may require aligning the workload to a different storage class to restore the intended behavior. Console indicates expected impact during the remediation flow.
====

== Verify compliance
