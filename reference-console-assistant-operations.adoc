= Supported Console assistant operations in NetApp Console local deployment
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Use the Console assistant in NetApp Console local deployment to ask natural-language questions and perform selected storage operations. Available operations depend on your assigned access role.
include::_include/ai-preview.adoc[]

Use the Console assistant in *Read only* mode for questions and analysis without infrastructure changes. Use *Read/write* mode for supported operations that can change storage or ONTAP systems. The assistant shows the proposed change and requires confirmation before it executes a write operation.

== Console assistant capabilities

The Console assistant supports the following operation categories. Available operations depend on your release, configured LLM endpoint, assigned roles, and resource scope.

[cols="28,18,54",options="header"]
|===
| Capability
| Access mode
| Use it to

| Conversational guidance and search
| Read only
| Ask questions about NetApp Console local deployment, your storage environment, and supported ONTAP administration workflows.

| Metrics and analytics
| Read only
| Analyze supported capacity, performance, and other metrics within your permitted scope.

| Storage provisioning
| Read/write
| Plan and provision supported volumes or LUNs after reviewing and confirming the proposed operation.

| Alert investigation and remediation
| Read only or read/write
| Investigate active alerts and review supported remediation actions before they change storage.

| ONTAP management
| Read only or read/write
| View or perform supported management operations on Console-associated systems.
|===

Use your assigned roles and organization, folder, or fleet scope to determine which systems and workloads the assistant can access. The assistant does not bypass Console local deployment access controls.

== Metrics and analytics

Ask read-only questions about supported storage capacity, performance, and other metrics for resources in your permitted scope. Include the resource, metric, and time period when those details are relevant to your question.

The assistant returns an analysis and does not change storage in *Read only* mode.

== Storage provisioning

Describe the workload and its storage requirements in natural language. The assistant can recommend a storage class and placement, identify missing details, and present a provisioning plan for review.

After you approve the plan, the assistant provisions the supported volume or LUN operation within your role permissions and storage-class policies. 
link:task-provisioning-agentic.html[Learn how to provision storage with AI-assisted workflows].

== Alert investigation and remediation

Ask the assistant to investigate an active alert. It analyzes the alert and may suggest a remediation action. When a supported remediation changes storage, the assistant presents the action for review and requires confirmation before execution.

Review the proposed remediation details and confirm the action before the assistant changes storage.

link:reference-alert-remediation.html[Learn about alert remediation actions.]

== ONTAP management

Request a supported management operation for a registered ONTAP system in natural language. Identify the target cluster, storage virtual machine (SVM), or resource when you know it so the assistant can use the correct context.

Review whether your request only reads information or changes an ONTAP system, then confirm any proposed write operation. The available operation set depends on the Console local deployment release and the permissions assigned to your account.

link:task-console-asst-use.html[Learn about using the Console assistant.]

== Permissions and scope

The assistant uses the permissions and resource scope of the signed-in user. Your assigned organization, folder, or fleet scope determines which systems and workloads the assistant can access.

* Your role determines which resources and operations you can view or change.
* Storage-class policies constrain AI-assisted provisioning.
* The assistant does not bypass Console local deployment access controls.

link:reference-iam-predefined-roles.html[Learn about NetApp Console local deployment access roles].

== Asynchronous operations

Ask the assistant for the status of a supported write operation that runs asynchronously. The assistant creates a job for operations that do not complete immediately.
