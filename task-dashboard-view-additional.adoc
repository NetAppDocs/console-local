= View additional dashboards in NetApp Console (local deployment)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Open the dashboards table to review predefined dashboards and any custom dashboards you create in one place.

== Before you begin

* Ensure your role allows access to *Storage > Dashboards*.

== Review dashboards in the dashboards table

In *Storage > Dashboards*, predefined dashboards and custom dashboards appear together in the same table. For example, use the table when you want to compare a finance dashboard with a production dashboard during a maintenance window.

.Steps

. Select *Storage > Dashboards*.

. Review the dashboard table to find the dashboard you want to open.

. Select the dashboard name to open it and view its metrics.

. If needed, use the available actions to edit, duplicate, or delete custom dashboards.
