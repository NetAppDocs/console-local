= Secure access to NetApp Console (local)
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
NetApp Console (local) provides multiple layers of security to protect your storage management environment and control who can access it.

== Active Directory integration

Connect NetApp Console (local) to your Active Directory so users can sign in with their existing corporate credentials. This eliminates the need for separate accounts and ensures that access changes in your directory are reflected automatically.

link:task-iam-active-directory-integrate.html[Integrate Active Directory with NetApp Console (local)]


== Multi-factor authentication

Users who aren't a part of your organization's single sign-on (SSO) setup can enable multi-factor authentication (MFA) for an additional layer of verification to prevent unauthorized access, even if credentials are compromised.

link:task-mfa-enable.html[Enable MFA for NetApp Console (local)]

== Access control

After authenticating users, control and monitor what they can do inside NetApp Console (local).

== Identity and access management

Use role-based access control to define what each user can see and manage. Assign users to specific fleets so they only access the storage resources relevant to their responsibilities.

* link:concept-identity-and-access-management.html[Learn about NetApp Console (local) identity and access management]
* link:concept-iam-rbac.html[Learn about NetApp Console (local) role-based access control]
* link:task-iam-manage-members-permissions.html[Add users to NetApp Console (local)]
* link:task-users-fleets-assign.html[Assign users to fleets in NetApp Console (local)]

== Audit logging

Track all user activity in NetApp Console (local) for compliance and security investigations.

link:task-audit-console-activity.html[View audit logs for NetApp Console (local)]
