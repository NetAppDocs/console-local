= Supported LLM providers and models in NetApp Console local deployment
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Supported provider types and model availability help you choose the right provider path and model for NetApp Console local deployment.

NetApp Console local deployment supports OpenAI and OpenAI-compatible provider types. The models available in the UI depend on the provider type and endpoint you configure.

== See how provider type affects model availability

Provider choice determines which models appear in the Console local deployment model list:

* *OpenAI* shows models supported for direct OpenAI integration.
* *OpenAI-compatible* shows models exposed by the compatible endpoint your organization configures.

Model availability can vary based on endpoint configuration, proxy or gateway behavior, and organizational policy. The difference between provider types is the endpoint you connect to and the models that endpoint exposes, not the transport protocol.

== Supported OpenAI models

* GPT-4.1
* GPT-5-mini
* GPT-5.1
* GPT-5.2

== Supported OpenAI-compatible models

* Claude Sonnet 4.5
* Claude Opus 4.5

== Choose the right LLM model

Use these guidelines when selecting a model:

* Choose a model that your provider path exposes in the Console local deployment UI.
* Use *Read only* mode first to validate response quality and policy alignment.
* Choose a model that matches your performance, cost, and governance requirements.
* If your organization uses an OpenAI-compatible endpoint, confirm available models with the service operator.
